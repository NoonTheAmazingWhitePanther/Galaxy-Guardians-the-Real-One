GOAL: Establish a simple, learnable gesture language for Galaxy Guardians.
Only 2 primary gestures: TAP and LONG-PRESS.
Each UI element can have different behaviors on TAP vs LONG-PRESS.

================================================================================

TAP vs LONG-PRESS PATTERN:

TAP (quick release):
  - Primary action (most common use case)
  - Fast feedback, instant result
  - Examples: toggle, increment, select

LONG-PRESS (hold 200-500ms then release):
  - Secondary action (less common, more powerful)
  - Confirmation action
  - Destructive or specialized action
  - Examples: reset to default, delete, extend range, fine-tune

DESIGN PRINCIPLE:
  Learning curve is shallow: "Tap for quick, Long-Press for powerful."
  Never require memorizing complex modifier combinations.

DESIGN NOTES:

- Tap is the "everyday" gesture — should be fastest, most responsive
- Long-press is the "power user" gesture — allows confirmation, fine-tuning, stats
- All actions must be visually reversible (toggle, not one-way)
- Feedback on long-press: visual change, haptic, sound cue
- No hidden combinations (Ctrl+Shift+Alt+Q) — everything discoverable
