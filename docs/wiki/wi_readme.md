# Wiki

This is the **future documented production key index and assets** folder —
not the working notes (`stuff/`), not the AI session summaries
(`summaries/`), not the backlog (`todo/`). This is where the *real*,
polished, "if a stranger opened this repo cold, this is what they'd read"
documentation eventually lives.

It's a placeholder right now. `wi_tree.md` (the module index) is the seed.

## What belongs here eventually
- Per-system architecture docs, written for a reader (not a handoff)
- Asset index / provenance
- Anything promoted out of `stuff/` once it's actually finished and correct

## What does NOT belong here
- Session summaries → `docs/summaries/`
- In-progress/unorganized notes → `docs/stuff/`
- Backlog/known-limitations → `docs/todo/`

## Naming
Every file here starts with `wi_`, lowercase — see `rules.md` §1 at the
repo root for the full convention.
